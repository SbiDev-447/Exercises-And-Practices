# Filtrar miembros únicos de un array

> Sea arr un array.

- Crea una función unique(arr) que debe devolver un array con los elementos únicos de arr.

Por ejemplo:
~~~ javascript

function unique(arr) {
  /* tu código */
}

let strings = ["Hare", "Krishna", "Hare", "Krishna",
  "Krishna", "Krishna", "Hare", "Hare", ":-O"
];

console.log( unique(strings) ); // Hare, Krishna, :-O
~~~

¡A por ello! 💪 Recuerda: debes devolver un nuevo array sin elementos duplicados, manteniendo el orden de la primera aparición de cada elemento.
