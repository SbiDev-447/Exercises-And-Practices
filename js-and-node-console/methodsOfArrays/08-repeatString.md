# Escribe una función que simplemente repita un string un número determinado de veces:

~~~javascript

repeatString('hey', 3) // devuelve 'heyheyhey'

~~~

> Esta función recibirá dos argumentos, `string` y `num`. Si num es un número negativo, devuelve el string `'ERROR'` en su lugar.

Usa bucles para implementar `repeatString` en lugar de usar el método incorporado String.prototype.repeat que tiene el mismo comportamiento.
